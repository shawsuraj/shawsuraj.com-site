World Chaos Map

A clear, honest picture of what is happening around the world, updated as it happens.

Every country gets a score from 0 to 100 based on what the news actually reports: deaths, arrests, airstrikes, curfews. Not on how much a country is talked about. Sudden crises surface by comparing each country with its own recent history, and events are placed where they happen.

How it got here

  1. Autumn 2025A weekend idea

    The news felt overwhelming. I wanted to see it all on one map.

  2. Jan to Feb 2026Live, early, then production

    Public on desktop first, with documentation on how it works and where it falls short. Automatic updates from day one.

  3. v2 · Mar 2026A real pipeline

    1,152 RSS sources, war zones scored correctly, underreported regions boosted, stable countries no longer inflated by global noise.

  4. v2.2 · Apr 2026NLP in the core

    The pipeline reads context and filters noise. Docs site lists every source.

  5. Jul 2026Orbit Mode

    A 3D globe that tours the day's hotspots on its own. Country pages, a weekly digest, a daily prediction game.

  6. v3.0 · Oct 2026A fairer score

    Rebuilt from scratch. Same news, same score, anywhere. News in 100+ languages, rescored every four hours.

  7. v3.1 · Oct 2026Built for phones

    A population weighted world score, why a score moved, Instagram Story cards, Higher or Lower, and a full security review.

  8. v3.2 · Oct 2026Accuracy first

    A hand run feed audit, 486 working feeds, robots.txt respected. Riots without deaths now stay below lethal violence. Full case study.
